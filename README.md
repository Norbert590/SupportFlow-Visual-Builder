# Visual Flow Builder Challenge

A lightweight, high-performance flow builder built with **React**, **Zustand**, and **Tailwind CSS**.

## 🚀 Features
- **Canvas Interface:** Drag and drop nodes with real-time SVG path updates.
- **State Management:** Powered by Zustand for predictable, high-speed updates.
- **Flow Logic:** Built-in ability to switch between 'Editor' and 'Preview' modes.
- **Pure SVG:** Custom Bézier curve logic for connections (no heavy external libraries).

## 🛠️ Setup
1. Run `npm install`
2. Run `npm run dev` or `npx vite`
3. Open `http://localhost:5173`
