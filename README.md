# SupportFlow Visual Builder

A lightweight, high-performance visual editor for chatbot decision trees, built with **React**, **Zustand**, and **Tailwind CSS**.

## 🚀 Key Features

* **Custom Graph Engine:** Implemented a pure SVG rendering system for dynamic Bézier curve connections without external libraries.
* **Editor & Preview Modes:** Seamlessly toggle between a visual building canvas and a functional preview mode.
* **State Management:** Powered by **Zustand** for high-speed updates and a predictable data structure.
* **Wildcard Feature - Smart Deletion:** Developed a contextual deletion system that automatically removes all associated edges (connections) when a node is deleted, maintaining graph integrity.

## 🛠️ Local Setup

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the local development server.
4. Open `http://localhost:5173` in your browser.
